# DAA Capstone

An academic courier and parcel planning project demonstrating core Design and
Analysis of Algorithms techniques:

- sorting parcels by priority
- 0/1 knapsack selection for courier capacity
- Dijkstra shortest paths between locations
- travelling salesperson route planning

## Project layout

See the `algorithms`, `core`, `data`, `tests`, `performance`, and `docs`
directories for the implementation, sample inputs, validation, benchmarking,
and project documentation.

## Run

```bash
python main.py
```

Run the test suite with:

```bash
python -m unittest discover -s tests
```
